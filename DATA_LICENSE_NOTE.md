# Data and redistribution note

This package does **not** redistribute raw Reddit, Google symptom-search, or CDC/NHAMCS records. Those sources remain subject to their original provider terms and must be reobtained from the cited providers.

`inputs/reported_summary.json` contains only small, manuscript-level reported summaries and archived server-level summary quantities required for the supplementary reanalysis. It is not a replacement for the original datasets.
